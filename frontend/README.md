# AI-exam-project

## Project Goal
Build a web-based system for:
- weekly assignments
- exam monitoring
- cheating detection (AI + browser tracking)

## Tech Stack
- Frontend: React + TypeScript + Vite
- Backend: Node.js
- Database: Supabase
- AI: Face Landmarker (MediaPipe)

## How to Run
1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Open browser at the URL shown in terminal
